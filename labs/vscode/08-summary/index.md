# Summary

## Shortcuts

Shortcut             | Does
---------------------|-------------------------------
`F1`, `Ctrl+Shift+P` | Command Palette
`Ctrl+P`             | Quick Open a file
`` Ctrl+` ``         | Terminal
`Ctrl+B`             | Show or hide the Side Bar
`Ctrl+,`             | Settings
`Ctrl+Shift+G`       | Source Control
`F5`, `F9`, `F10`    | Debug, breakpoint, step over

Cmd replaces Ctrl on macOS.

---

## Good practices

- Learn the Command Palette first, every other shortcut can be found from it.

- Commit `.vscode/settings.json` and `.vscode/extensions.json`, so the team shares them.

- Install few extensions, from known publishers, as each one runs with the user's rights.

- Keep the terminal at hand: VS Code and the command line run the same tools.
