## On a workstation

VS Code is a desktop application, available for Windows, macOS and Linux.

System         | Command
---------------|--------------------------------------------------------------------------
Windows        | `winget install --id Microsoft.VisualStudioCode -e`
macOS          | `brew install --cask visual-studio-code`
Debian, Ubuntu | `sudo apt install ./<file>.deb`, with the package from the download page
Fedora         | `sudo dnf install code`, once the Microsoft repository is added

[code.visualstudio.com/download](https://code.visualstudio.com/download) is the reference for every system.

The lab has no desktop, so VS Code runs as a server and is used from the lab's own browser.
