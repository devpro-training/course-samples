# VS Code essentials

The code editor most developers work in.

---

## Editor or IDE

- A **code editor** edits text, with syntax highlighting and search.

- An **IDE**, Integrated Development Environment, also builds, runs, tests, debugs and tracks changes, in one window.

- **VS Code** is an editor that becomes an IDE for a language through extensions.

- Full IDEs: Visual Studio for .NET and C++ on Windows, JetBrains IntelliJ IDEA, Rider and PyCharm.

---

## Visual Studio Code

- Free, by Microsoft, for Windows, macOS and Linux.

- Built on an open source project, **Code - OSS**, under the MIT license.

- Thousands of extensions, for every language and tool.

- Runs on a desktop, or as a server used from a browser, like **code-server** in this lab and GitHub Codespaces.
