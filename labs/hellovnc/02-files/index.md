# Exploring Files

Now let's run a few commands to explore the filesystem.

[Switch to browser](:panel:browser)

[Back to terminal](:panel:terminal)

## List files

Run `ls` to see what's in the current directory (the course folder):

```bash exec
ls
```

## Detailed listing

Add the `-la` flag for a detailed view with hidden files and permissions:

```bash exec
ls -la
```

## Where are we?

```bash exec
pwd
```

## System info

```bash exec
uname -a
```
